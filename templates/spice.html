ผลตรวจตอนสร้างรุ่น

    ผู้ดูแลรุ่นออนไลน์เป็นผู้เลือก ngspice และโมเดลของระบบ เปิดแท็บ DC, AC หรือ Transient เพื่อทดลองได้จากเบราว์เซอร์

    1. ติดตั้งบนเครื่องที่รัน Workbench

    ดาวน์โหลด ngspice จาก เว็บไซต์ของผู้พัฒนา บน Windows ใช้รุ่น portable แล้วแตกไฟล์ไว้ในโฟลเดอร์ที่เข้าถึงได้ บน macOS ใช้ Homebrew และบน Ubuntu/Debian ใช้ตัวจัดการแพ็กเกจของระบบ

    2. เตรียมโปรไฟล์โมเดล

    ใช้โมเดลจากผู้สอนที่ทราบแหล่งที่มา หรือ onsemi 2N3904 สำหรับสาธิตบนเครื่อง ไฟล์ที่เลือกจะอยู่ในเบราว์เซอร์เพื่ออ่านชื่อโมเดลและคำนวณ SHA-256

    เลือกประเภทนี้ตามแหล่งที่มาของไฟล์ ผลตรวจวงจรและความพร้อมจะขึ้นหลังรันชุดตรวจ

    จับคู่ขา .SUBCKT ตามลำดับในไฟล์

    แทน MODEL_FILE ด้วยชื่อไฟล์ที่เลือก แล้วใช้ Get-FileHash -Algorithm SHA256 -LiteralPath '.\MODEL_FILE' ใน PowerShell, shasum -a 256 'MODEL_FILE' บน macOS หรือ sha256sum 'MODEL_FILE' บน Linux

    3. เปิด Flask ใหม่และกลับมากดทดสอบ

    วาง profile.json กับไฟล์โมเดลในโฟลเดอร์เดียวกันนอก Git แทนค่าพาธในตัวอย่าง แล้วเปิด Flask จากโฟลเดอร์โปรเจกต์ที่ติดตั้ง Python dependencies แล้ว

    Windows · PowerShell

    ถ้า ngspice -v ใช้ได้แล้ว ข้ามบรรทัด LAB04_NGSPICE ได้

    $env:LAB04_SPICE_PROFILE = 'C:\path\to\models\profile.json'
$env:LAB04_NGSPICE = 'C:\path\to\Spice64\bin\ngspice_con.exe'
$solver = if ($env:LAB04_NGSPICE) { $env:LAB04_NGSPICE } else { 'ngspice' }
& $solver -v
.\.venv\Scripts\python.exe -m flask --app app run --host 127.0.0.1 --port 8780
    macOS / Linux 
    # macOS: brew install ngspice
# Ubuntu/Debian: sudo apt install ngspice
ngspice -v
export LAB04_SPICE_PROFILE="/path/to/models/profile.json"
.venv/bin/python -m flask --app app run --host 127.0.0.1 --port 8780

    ถ้าเครื่องนี้ติดตั้งไม่สำเร็จ ใช้รุ่น portable บน Windows หรือเปิดจากเครื่องแลปที่ตั้งค่าครบ ระหว่างเตรียมเครื่องใช้ เครื่องคำนวณมือ Lab 03 ได้
